# Rust Journey

A collection of fun exercises documenting my journey to master Rust.

## Running Rustlings exercises

Specific Rustlings can be run by specifying the exercise name.

```sh
cargo run -p rustlings --bin intro1
```

## Running Rustlings
To run the rustlings CLI, move the the rustlings folder and start rustlings.

```sh
cd rustlings && rustlings
```

## Running other exercises
Exercises from the exercises folder can be run by specifying the name of the project only.

```sh
cargo run -p temp_converter
```
